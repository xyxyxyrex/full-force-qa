# Parity 1.4.4

## Cross-browser comparisons

- Compare the active Chromium preview with Firefox or WebKit full-page captures in a canvas card. Chromium remains the default live preview.
- Scroll between the live page and comparison capture, review saved captures, annotate differences, and delete old comparisons.
- Drag the comparison card by its header in Edit and Live. Capture a fixed-width viewport column when a page overflows horizontally.

## Edit polish

- Font Display transparency and scale now update the Edit overlays. Labels show the full font family, size, and weight, with wrapping instead of truncation on narrow viewports.
- The collapsed viewport toolbar opens from its small handle, avoiding accidental activation while moving across the canvas.
- Mobile previews hide their internal scrollbars while retaining scrolling.

No Supabase schema migration is required for this release.
