# Parity v1.5.4

- Detach the QA agent chat into a native movable, resizable desktop window. Dock it again without losing messages, progress, token counts or unsent text.
- Browse compact provider settings with local SVG logos, searchable model discovery, custom model IDs and loading skeletons. Change agents or models without reopening the project.
- Read formatted, streamed answers with Markdown tables, code copying, slash-command discovery, live waiting timers and grouped tool activity.
- Recover failed work with dedicated Retry actions, bounded provider retries, completed-stage checkpoints and safeguards against repeating submissions.
- Organize automatically saved findings by project and page. Review, edit, accept or dismiss them in Findings or the managed AI Findings tracker worksheet; retain annotated evidence locally.
- Choose remark tone, technicality, detail and optional light formatting in Settings → Agents. Share evidence explicitly through approval; copying rows is optional.
- Extend Windows CI and installer release checks with native detached-chat regressions. Update the Cloudflare viewer and PowerShell installer to v1.5.4.

Existing projects and histories remain supported. No Supabase migration is needed for this release.
