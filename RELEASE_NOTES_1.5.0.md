# Parity v1.5.0

Parity v1.5.0 is the first public release.

## Highlights

- Add dashboard Multi-capture with bulk URL parsing, spreadsheet paste, manual rows, duplicate handling, folder destinations, progress, stop, and retry support.
- Add Alt-held Free Transform in Edit: proportional scaling, axis stretching, unconstrained translation, transient measurements, undo/redo, and reset.
- Restore reliable DOM Layers and Styles editing, including attribute, node, declaration, and themed control interactions.
- Improve Figma comparison controls, browser-engine selection, guides, inspector inputs, responsive panels, and theme consistency across workspace overlays.
- Add clear Monday connection and refresh errors for permissions, credentials, account restrictions, missing resources, rate limits, outages, and network failures.
- Expand Windows CI and the release gate with Multi-capture and Free Transform Electron regressions.

## Distribution

- Windows NSIS installer and automatic update metadata are published with this release.
- The public landing page, installer bootstrapper, and ephemeral review viewer are hosted at https://parity-gfx.pages.dev.
- Supabase migration history is synchronized through the feedback/reporting schema; this release adds no new database migration.
